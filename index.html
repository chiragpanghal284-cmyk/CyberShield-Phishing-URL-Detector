    How it works

    🔢
    IP Hostname

    Flags URLs that use a raw IP address instead of a domain name.

    📏
    URL Length

    Very long URLs (100+ chars) are a common phishing tactic.

    @
    @ Symbol

    An @ in the host causes browsers to ignore the text before it.

    🌐
    Subdomain Depth

    Excessive subdomains mimic trusted brands.

    🔑
    Suspicious Keywords

    Words like "login", "verify", "password" in the URL path.

    🔒
    HTTPS Check

    HTTP (not HTTPS) means data travels unencrypted.

    ➖
    Hyphen in Domain

    Hyphens in the domain often spoof brand names (pay-pal.com).

    ↪
    Double Slash Redirect

    Double slashes in the path may indicate a redirect attempt.
